# 三千影录

在三千影录的代码目录中运行 `review.py`。若当前只是独立安装的 Skill，先定位仓库源码。配置方法和模块边界见仓库的 [使用与判定说明](../../docs/analysis.md)。玩家口吻与报告解读见 [玩家指南](references/player-guide.md)。

1. 确认回合范围、A/B 身份、忍者版本和特殊槽位顺序。从双方血条基本完整的片段校准 HUD。未读清的角色版本和槽位保留候选。
2. 使用 `engine/` 的血条、图标和可用倒计时线索建立时间线。保留有释放线索但没有掉血的动作，也保留无对应图标的伤害。角色机制来自用户提供的资料或可用的忍者库。
3. 优先回看片段解决关键冲突。按前摇、后摇、换位、刷新、再次释放拆开过程。对命中、掉血、位移、抗控、控制、打断和替身分别判定。打断允许与同期伤害并存，起手需要核实命中和对手无法自行脱身。
4. 将能核实的动作和备选分支填入回合配置，再用 `frontend/` 生成报告。实战结果要能回跳原片；未发生的走法只作为复盘选项。报告中用玩家术语解释双方各交了什么、换来什么和何处待核。
