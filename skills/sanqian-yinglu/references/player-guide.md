# 三千影录 · 玩家指南

一波交手过得太快时，先回看双方出招前手里有什么，再看交出去的技能换来了什么。

| 想看什么 | 去哪看 |
| --- | --- |
| 谁先出招，后面怎么断了 | 点**录像复盘**的事件，回到交手前。 |
| 对面交了几个资源，我还剩什么 | 对照**技能甘特图和血量折线**。冷却是状态，出招与替身是事件。 |
| 如果我换个打法，会省下什么 | 进**双方博弈树**，沿实线追实际交手，沿虚线看备选。 |

比如佐助替身接雷剑，水门用飞雷神换位躲开。这一波能复盘的不只是有没有掉血，还有佐助是否值得在替身后立刻交三技能，以及水门为避开这一下付出了一技能。

遇到「待核」，可以跳回相关动作。普攻、换位和派生可能没有单独图标。想确认有没有起手，要看对手受击后能不能自行行动、是不是靠交替身才脱开。
