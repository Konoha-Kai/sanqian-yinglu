# 三千影录

火影忍者手游决斗场复盘工具。用录像、技能甘特图、血量曲线和双方博弈树拆开每一波交手，看看谁在什么时候出招、谁交了替身，以及哪一次换位或打断改变了走势。

> [!IMPORTANT]
> **三千影录完全通过录像分析实现，未对《火影忍者》手游进行逆向工程。** 程序只分析录制好的对局画面，从玩家可见的血条、技能图标和倒计时提取线索，再通过回放核对动作。分析不读取游戏进程、内存或网络通信。

- **录像复盘**呈现掉血、资源变化和已经复核的重点事件。点时间回到出招前。
- **技能甘特图与血量折线**并列展示双方。底条是技能图标状态，刻度是出招线索，复核标记有独立图例。
- **双方博弈树**按 A、B 分列展示动作与应对。实线是实际事件或按时间排列的线索，虚线是复盘时补充的备选走法。

比如佐助替身后出雷剑，水门用飞雷神换位躲开。资源表能告诉你双方各交了什么。回到录像核对后，才能把雷剑没打中和水门换位联系起来。另一个例子是镰鼬打断技能后续时，水门此前或同期仍可能吃到伤害，报告会保留这两项记录。

## 跑一场自己的录像

准备一段本地 MP4 回放和一个回合的原视频起止时间。示例里的 `8.7` 和 `42.95` 请换成你自己的时间。

```sh
python -m pip install -r requirements.txt
python review.py replay.mp4 --round 8.7 42.95 --output out
python serve.py --directory out
```

浏览器打开 <http://127.0.0.1:8672/>。分析默认从多帧稳定画面定位双侧血条和技能槽，回合起点最好选在双方血条基本完整的位置。使用浏览器可播放的 MP4。录像和报告都留在本地。

多回合、忍者名、特殊槽位与人工复核的配置说明见[使用与判定说明](docs/analysis.md)。

## 仓库里有什么

| 目录 | 负责什么 |
| --- | --- |
| [engine/](engine/) | 定位血条和技能栏，测量变化，筛选倒计时和攻防事件，判断有哪些证据支持命中、打断、起手或资源交换。 |
| [frontend/](frontend/) | 可点击的录像复盘、技能甘特图、血量曲线和双方博弈树。 |
| [skills/sanqian-yinglu/](skills/sanqian-yinglu/) | 给 Codex 的复盘 Skill。说明如何调用判定代码、核对存疑动作并生成报告。 |

纯色变化会有误报。普攻、换位和特殊派生经常需要按段回看。技能图标进冷却和对手掉血的先后关系只作为归因线索，录像中有证据表明这一击限制了对手自主行动、对手无法自行脱身，才确认起手。
